AC KING WEBSITE — QUICK START

Files:
- index.html: the website. Open it in a browser to preview.

BEFORE PUBLISHING:
1. Replace the empty AC_KING_WHATSAPP value near the bottom of index.html with the real WhatsApp number, digits only. For Jamaica, use 1 + the 10-digit number.
2. Add the real phone number, business email, location/service area, opening hours, and exact services.
3. Replace illustrative stock photos with authentic AC King product and service photos.
4. Check every product/service description for accuracy.

FREE PUBLISHING OPTION:
- GitHub Pages can host a static HTML website for free.
- Create/sign into a GitHub account, create a public repository named ac-king-website, upload index.html, then open Settings > Pages and select Deploy from a branch, branch main, folder /(root), and Save.
- The published URL will appear in the Pages settings. GitHub's interface may change over time.
- Alternative: use a static hosting provider's free tier and upload the website files, checking current plan limits first.

NOTE:
This is a front-end business website. It does not have a live product inventory, checkout, booking system, or form backend. WhatsApp enquiry links activate after the number is added.
